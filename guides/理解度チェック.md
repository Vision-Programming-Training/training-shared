# 課題に入る前の理解度チェック

課題（A1〜）に取りかかる前に、**「課題を解くための地図」が頭に入っているか**を確かめるチェックです。<br>
点数は付けません。**分からなかったところ＝課題で詰まりやすいところ**を、先に見つけておくのが目的です。

| 項目 | 内容 |
|---|---|
| 形式 | 筆記（第1〜4部）＋ ハンズオン（第5部） |
| 目安時間 | 筆記 45〜60分 / ハンズオン 1.5〜2時間 |
| 資料 | **見てOK**（このリポジトリの資料・コード・検索）。ただし答えを丸写しせず、自分の言葉で書く |
| 完了の目安 | 筆記の全問に回答（分からなければ「分からない」と書く）＋ ハンズオン全項目完了 |

事前に読んでおく資料:

- [Web アプリケーション基礎レクチャー](../web/Web基礎.md)
- [受講者ガイド](受講者ガイド.md) の §1〜§4
- [データモデル](../db/データモデル.md)
- バックエンド・フロントエンドの各 README
- （Git に不安がある人）`git-practice` の README

> 答えは下の各問の「回答欄」に書き込み、講師に提出してください。
