# 課題FC4（★★☆・機能追加）管理画面の価格欄を Enter / Esc で操作する

## 背景

管理画面で価格を変えるたびにマウスでボタンを押すのが面倒。キーボードで操作できるようにしたい。

## 要件

- 価格欄で Enter を押すと「価格を更新」と同じ処理をする。
- Esc を押すと、入力を現在の価格に戻す。
- 日本語入力（IME）の変換確定の Enter では更新しない。

## この課題で学ぶこと

- `keydown` イベントと `event.key`
- 既存の更新処理を**再利用**する（同じ処理を2か所に書かない）
- `event.isComposing`

## 進め方

- ブランチは `training-frontend` の `main` から切る。
- 実装後、要件をすべて満たすことと、[受講者ガイド §3](../受講者ガイド-frontend.md#3-テストの代わりに--動作確認チェックリスト) の動作確認チェックリストが全部 OK であることを確認する。
- PR には「どのファイルに何を置いたか（なぜそこか）」も書く。
