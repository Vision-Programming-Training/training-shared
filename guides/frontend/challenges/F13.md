# 課題F13（★★★）注文をキャンセルすると別の注文がキャンセルされる

## 現象

注文履歴で、一番上の注文の「注文をキャンセル」を押すと、**別の注文番号**の確認ダイアログが次々と出て、その注文がキャンセルされてしまう。2件目以降の注文のボタンは押しても何も起きない。

## 再現手順

1. （できれば backend の DB を初期化しておく）
2. 注文履歴ページを開く。
3. 一番上の注文の「注文をキャンセル」を押す。
4. 確認ダイアログに出る注文番号が、押した注文と違う。OK を押すとその注文がキャンセルされ、さらに別の注文の確認が出る。
5. 2件目以降の「注文をキャンセル」は押しても反応しない。

## 期待結果

- 押した注文の番号で確認ダイアログが1回だけ出て、その注文だけがキャンセルされる。
- どの注文のボタンも反応する。

## 調べ始めのヒント

- 各ボタンに付いている処理の数を Event Listeners で見てみよう。処理はどのボタンに集まっている？
