# 課題F15（★★☆）無効なクーポンでも「注文が完了しました」と出る

## 現象

存在しないクーポンコードで注文すると「注文が完了しました！」と表示される。だが注文番号は undefined で、注文履歴にも注文は無い。

## 再現手順

1. 店舗ページでノートをカートに入れる。
2. クーポン欄に `SALE99` と入れて注文する。
3. 「注文が完了しました！ 注文番号: undefined ステータス: 400 …」と表示される。
4. 注文履歴を見ても、その注文は無い。

## 期待結果

- 「クーポンが無効です (Code: SALE99)」がエラーとして表示される。
- 有効なクーポン（`SALE10` など）やクーポンなしの注文は従来どおり成功する。

## ヒント

- Network で注文のリクエストを選び、サーバーが返したステータスコードと本文を確認しよう。サーバーとフロント、どちらが間違っている？
