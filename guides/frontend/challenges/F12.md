# 課題F12（★★★）件数表示を足したらカートの「削除」が効かなくなった

## 現象

最近「カートに何種類入っているか」を表示する機能が追加された。表示自体は出ているが、それ以来カートの「削除」ボタンを押しても何も起きない。Console にエラーも出ない。

## 再現手順

1. 店舗ページを開く。
2. ノートとマグカップをカートに入れる。カートの下に「2 種類」と表示される。
3. どちらかの「削除」を押しても何も起きない。

## 期待結果

- 「削除」を押すとその行が消え、小計と件数表示も変わる。
- **件数表示の機能は残したまま**直すこと。

## ヒント

- Elements の Event Listeners で「削除」ボタンを見てみよう。押したときの処理は付いている？
