# 課題FC5（★★★・機能追加）`alert` の代わりにトースト通知を出す

## 背景

「在庫は◯個までです」やキャンセル失敗などで `alert()` のダイアログが出ると、操作が止まって煩わしい。画面の隅に数秒だけ出て消える「トースト通知」に置き換えたい。

## 要件

- `js/ui/components/toast.js` に通知を出す関数を作る（`topbar.js` と同じく、自分で DOM を作る部品）。
- 全ページの `alert()` をトースト通知に置き換える（`confirm()` はそのままでよい）。
- 数秒で自動的に消え、消えた後は DOM に残らない。
- 続けて出したときは重ならず縦に積まれる。
- 成功とエラーで色を分ける。共通のスタイルは `css/common.css` に置く。

## この課題で学ぶこと

- DOM 部品をモジュールにする設計
- `setTimeout` と要素の生成・削除
- 文言を入れるときは安全な方法で（F17 を思い出そう）

## 進め方

- ブランチは `training-frontend` の `main` から切る。
- 実装後、要件をすべて満たすことと、[受講者ガイド §3](../受講者ガイド-frontend.md#3-テストの代わりに--動作確認チェックリスト) の動作確認チェックリストのうち、影響範囲の項目が OK であることを確認する。
- PR には「どのファイルに何を置いたか（なぜそこか）」も書く。
