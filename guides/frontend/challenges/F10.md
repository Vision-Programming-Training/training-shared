# 課題F10（★★☆）「カートに追加」ボタンが最後の商品にしか無い

## 現象

店舗ページで、「カートに追加」ボタンが一覧の最後の商品（キーホルダー）にしか表示されない。しかもそのボタンを押すと、いろいろな商品がまとめてカートに入る。

## 再現手順

1. 店舗ページを開く。ボタンがキーホルダーの横にしか無い。
2. そのボタンを押す。
3. ステッカーの在庫アラートが出て、カートにはキーホルダー以外の商品も入る。

## 期待結果

- すべての商品にボタンがある（ステッカーは「在庫切れ」で押せない）。
- 押した商品だけがカートに入る。

## 調べ始めのヒント

- ボタンの要素はいくつ作られている？ Elements の Event Listeners でボタンに付いている処理の数も見てみよう。
