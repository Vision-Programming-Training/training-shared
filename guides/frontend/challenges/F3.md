# 課題F3（★☆☆）管理画面で正しい価格を入れてもエラーになる

## 現象

管理画面で商品の価格を変更しようとすると、正しい数値を入れても必ずエラーになり、価格を変えられない。

## 再現手順

1. 管理ページを開く。
2. ノートの価格欄を `500` に書き換える。
3. 「価格を更新」を押す。
4. 「価格は 0 以上の数値で入力してください。」と表示される。

## 期待結果

- `500` など 0 以上の数値なら、その価格に更新され「…の価格を ¥500 に更新しました。」と表示される。
- マイナスの値は従来どおりエラーになる。

## ヒント

- 入力された値が、チェックの時点で**どんな型**になっているか確かめよう。
