# 課題F14（★★☆）注文完了メッセージが「undefined」「¥NaN」になる

## 現象

店舗ページで注文すると、完了メッセージの注文番号やステータスが「undefined」、金額が「¥NaN」になる（注文履歴を見ると注文自体はできている）。
また、無効なクーポンで注文しても同じ「注文が完了しました！」が出て、カートが空になる（実際には注文できていない）。

## 再現手順

1. 店舗ページでノートをカートに入れ、クーポンなしで注文する。
2. 「注文番号: undefined」「お支払い金額（税込）: ¥NaN」と表示される。
3. もう一度ノートを入れ、クーポン欄に `SALE99` と入れて注文する。
4. また「注文が完了しました！ 注文番号: undefined …」と出てカートが空になる。注文履歴には増えていない。Console には赤いエラーが出ている。

## 期待結果

- 正常な注文では、注文番号・ステータス・税込金額が正しく表示される。
- 無効なクーポンでは「クーポンが無効です (Code: SALE99)」がエラーとして画面に表示され、カートはそのまま残る。

## ヒント

- 注文 API を呼んだ結果を受け取る変数に、ブレークポイントで止めて何が入っているか見てみよう。
