# 課題F1（★☆☆）キャンセルした注文が「確定」のまま表示される

## 現象

注文履歴で注文をキャンセルすると「注文をキャンセル」ボタンは消えるのに、バッジは「確定」のまま表示される。サーバー側ではキャンセルできている。

## 再現手順

1. 注文履歴ページを開く。
2. どれか1件の「注文をキャンセル」を押し、確認ダイアログで OK を押す。
3. 一覧が再表示され、その注文のボタンは消えるが、バッジは「確定」のまま。

## 期待結果

- キャンセルした注文は「キャンセル済み」バッジになり、「注文をキャンセル」ボタンは出ない。
- まだキャンセルしていない注文は「確定」のまま。

## ヒント

- Network でサーバーが返している `status` の値と、画面に出ているバッジを見比べてみよう。
