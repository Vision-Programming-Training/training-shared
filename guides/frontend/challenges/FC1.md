# 課題FC1（★☆☆・機能追加）商品を名前で絞り込む検索ボックス

## 背景

商品が増えてきたので、店舗ページで商品を名前で絞り込めるようにしたい。

## 要件

- 商品一覧の上に検索ボックスを置く。
- 入力するたびに、商品名に入力文字を**含む**商品だけを表示する（例: 「ノ」→ ノート）。
- 空にすると全件表示に戻る。該当なしなら「商品がありません。」と表示する。
- **サーバーへは問い合わせ直さない**（すでに取得した一覧を使う）。
- 絞り込み中でも「カートに追加」は押した商品で正しく動く。

## この課題で学ぶこと

- `input` イベント
- 配列の `filter`
- 「データ → 描き直す」の流れ

## 進め方

- ブランチは `training-frontend` の `main` から切る。
- 実装後、要件をすべて満たすことと、[受講者ガイド §3](../受講者ガイド-frontend.md#3-テストの代わりに--動作確認チェックリスト) の動作確認チェックリストが全部 OK であることを確認する。
- PR には「どのファイルに何を置いたか（なぜそこか）」も書く。
