# 課題FC2（★★☆・機能追加）カートの数量を「−」「＋」で変える

## 背景

今はカートの数量を増やすには「カートに追加」を何度も押すしかない。カートの中で数量を変えられるようにしたい。

## 要件

- カートの各行に「−」「＋」ボタンを置く。
- 「＋」で数量 +1。在庫数に達したら「＋」は押せない。
- 「−」で数量 −1。0 になったらその行を削除する。
- 数量を変えると行の金額と「税抜小計（目安）」も変わる。
- 注文時には変更後の数量で送られる。

## この課題で学ぶこと

- 数量の計算は `core/cart.js`（DOM を触らない）に置き、画面は `ui/render.js`、つなぎは `entries/shop.js` という分担
- `createElement` とイベント

## 進め方

- ブランチは `training-frontend` の `main` から切る。
- 実装後、要件をすべて満たすことと、[受講者ガイド §3](../受講者ガイド-frontend.md#3-テストの代わりに--動作確認チェックリスト) の動作確認チェックリストのうち、影響範囲の項目が OK であることを確認する。
- PR には「どのファイルに何を置いたか（なぜそこか）」も書く。
