# 課題F16（★★☆）注文ボタンを連打すると同じ注文が2件できる

## 現象

「この内容で注文する」を素早く2回押すと、同じ内容の注文が2件作られ、在庫も2回分減ってしまう。

## 再現手順

1. DevTools の Network パネルで、スロットリングを「Slow 4G」などにする（通信を遅くして再現しやすくする）。
2. 店舗ページでノートをカートに入れる。
3. 「この内容で注文する」を素早く2回押す。
4. 注文履歴を見ると、同じ内容の注文が2件ある。
5. （終わったらスロットリングを「No throttling」に戻す）

## 期待結果

- 何回押しても注文は1件だけ作られる。
- 通信が終わったら、またボタンを押せる状態に戻る。

## ヒント

- Network で注文のリクエストが何本出ているか見よう。通信中、ボタンはどんな状態であるべき？
