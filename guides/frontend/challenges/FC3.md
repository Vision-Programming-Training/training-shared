# 課題FC3（★★☆・機能追加）注文明細を開いたり閉じたりできるようにする

## 背景

注文が増えると注文履歴が長くなって見づらい。明細表を普段は閉じておき、必要なときだけ開けるようにしたい。

## 要件

- 各注文の明細表は最初は閉じておく。
- 「▶ 明細を見る」ボタンで開き、開いているときは「▼ 明細を閉じる」と表示する。
- 注文ごとに独立して開閉できる。
- キャンセル後の再表示でも正しく動く。

## この課題で学ぶこと

- `hidden` 属性 / `classList.toggle`
- `aria-expanded` で開閉状態を伝える（アクセシビリティ）

## 進め方

- ブランチは `training-frontend` の `main` から切る。
- 実装後、要件をすべて満たすことと、[受講者ガイド §3](../受講者ガイド-frontend.md#3-テストの代わりに--動作確認チェックリスト) の動作確認チェックリストのうち、影響範囲の項目が OK であることを確認する。
- PR には「どのファイルに何を置いたか（なぜそこか）」も書く。
